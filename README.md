# AI-KnowledgeHub Git Snapshot

This repository stores the Git-friendly knowledge, configuration, templates, manifests, and Codex synchronization state from `D:\Evan\AI-KnowledgeHub`.

The `vault/` directory is generated by `scripts/sync_from_vault.py`. Raw SQL dumps, images, office binaries, audio, and video remain outside Git. Two source notes with password-like content are also excluded pending manual review.

## Refresh locally

```powershell
python -X utf8 .\scripts\sync_from_vault.py
python -X utf8 .\scripts\check_no_secrets.py
```

## Commit and push

`scripts\sync_and_push.ps1` requires a repository-root marker named `.allow-remote-push`. Create that marker only after confirming the configured remote is private or after the user explicitly authorizes publishing to a public remote. The marker is ignored by Git.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\sync_and_push.ps1
```

The three-day Codex Obsidian automation should call this script only after its note/state validation succeeds.
