# V2 视觉搜索策略

## 总体理解

这篇不是泛泛讲芯片，而是在讲“旧规则”和“换路线”：

- 旧规则：摩尔定律、先进制程、美国定义的生产力指标。
- 旧规则为什么难：EUV、EDA、材料、晶圆制造、产业链协同。
- 美国为什么能卡：中国芯片被卡在规则体系和产业链节点上。
- 华为的转折：不继续完全沿着美国定义的先进制程路线卷，而是提出新思路。

所以素材不能只搜“芯片”“科技”，必须按论证角色找。

## 镜头素材优先级

1. `摩尔定律`：Gordon Moore / Intel / Computer History Museum / Moore's Law explainer 视频。
2. `芯片越小、晶体管越多`：芯片微观、晶体管可视化、microchip zoom。
3. `美国主导规则`：白宫 CHIPS Act、美国商务部、国会、C-SPAN 半导体政策。
4. `7nm/5nm/3nm/2nm`：IBM 5nm、2nm、晶圆厂、EUV、先进制程官方视频。
5. `越来越贵越来越难`：ASML EUV、半导体高端设备、清洁室工程。
6. `光刻机/EDA/材料/晶圆制造`：EUV + EDA软件界面 + 硅片材料 + 晶圆厂生产线。
7. `美国卡中国芯片`：BIS出口管制、美国商务部、中国芯片限制听证会、白宫供应链会议。
8. `华为新路线`：华为园区航拍、华为工厂、华为实验室、华为发布会、华为官方技术视频。
9. `韬定律`：韬定律原始发布/解释视频；找不到再用华为芯片架构、先进封装、chiplet 临时替代。

## 禁止策略

- 不用图片顶替视频。
- 不复用同一个视频给多个镜头。
- 不用国旗代替美国半导体政策。
- 不用 NASA 工程师代替华为。
- 不用抽象科技背景代替具体公司、具体工厂、具体发布会。
- 不只根据单个关键词搜索，要说明素材如何表达该句在全文里的作用。
