# V2.3.1实战应用复盘 2026-W23

## 模型口径

本周使用的主模型是 V2.3.1 利润池择优框架，核心不是找“最正宗”的题材股，而是判断谁控制利润池、谁存在预期差、谁能被资金持续定价。

完整判断维度：

1. 宏观与行业面。
2. 公司基本面与核心竞争力。
3. 财务质量。
4. 当前估值与赔率。
5. 影子股逻辑加成。
6. 估值重构逻辑。
7. 流动性、治理和交易强弱。

V2.3.1 的修正重点：

- 产业链利润池位置。
- 母子公司和影子股穿透。
- 预期差与已定价程度。
- 客户集中度折扣。
- 二阶增长趋势。
- 同题材相对强弱。
- 组合暴露折扣。

## 本周重要修正

### 1. 题材正确不等于交易正确

例如 AI硬件、光模块、先进封装长期逻辑仍在，但周末外盘科技股大跌会显著影响周一交易情绪。因此需要把“产业评分”和“交易评分”拆开。

### 2. 卖铲人要分层

卖铲人不是简单地提供工具，而是要判断其产品是否卡住利润池：

- 原材料和关键辅材。
- 制程设备。
- 设计工具。
- 测试和封装工具。
- 训练和仿真平台。

越靠近不可替代的瓶颈环节，越适合获得估值重构。

### 3. 影子股逻辑必须有触发条件

影子股逻辑不能只停留在“有关联”。需要满足：

- 龙头事件有确定催化。
- 被映射公司处在同一利润池或供需瓶颈。
- 市场尚未完全定价。
- 有财务或订单迹象支撑。

### 4. 估值重构要看边际变化

估值重构来自身份变化，例如：

- 从传统材料变成 AI服务器材料。
- 从消费电子零部件变成 AI硬件卖铲人。
- 从设备跟随者变成国产替代核心供应商。
- 从题材股变成有业绩弹性的主线资产。

## 本周个股研究沉淀

| 标的 | 研究重点 | 结论 |
|---|---|---|
| 国瓷材料 | MLCC、AI服务器材料、电子陶瓷、估值重构 | 符合“传统材料向 AI材料利润池迁移”的重估逻辑 |
| 联瑞新材 | 球形硅微粉、电子封装材料、财务与估值、护城河 | 基本面逻辑成立，但交易强度和估值压力需要单独折扣 |
| 生益科技 | PCB/CCL、高端覆铜板、AI服务器材料 | 处在 AI硬件材料卖铲人方向，核心度高 |
| 新易盛 | 光模块、高速光互联、AI集群 | 长逻辑强，短线受外盘科技股影响大 |
| 绿的谐波 | 机器人减速器、物理AI | 物理AI辨识度强，但涨幅后需要看承接 |

## 本周形成的操作原则

1. 强主线中也要分核心仓和弹性仓。
2. 亏损弱仓不能因为“逻辑还在”无限摊薄。
3. 外盘大跌时，高贝塔 AI硬件先防守，再判断修复。
4. 已有浮盈的核心仓，优先守利润，而不是盲目加仓。
5. 个股评分要同时输出：产业评分、财务评分、估值评分、交易评分、风险折扣。
