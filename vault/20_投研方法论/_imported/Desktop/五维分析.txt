## 1. 框架总览

### 1.1 设计目标

本框架旨在系统化地解决以下问题：

- 如何在数千只股票中筛选出具有**长期投资价值**的标的？
- 如何在"看似低估"和"真正陷阱"之间做出区分？
- 如何量化**赛道景气度、护城河、盈利质量、估值空间、套利机会**？
- 如何在认知差形成前提前布局？
- 如何避免重大风险（治理风险、财务造假、流动性枯竭）？

### 1.2 框架结构

```
┌──────────────────────────────────────────────────┐
│                 一票否决（Veto）                   │
│   治理风险 / 持续亏损 / 主力撤退 / 应收异常        │
└──────────────────────────────────────────────────┘
                         ↓
┌──────────────────────────────────────────────────┐
│                 六维评分体系                        │
├──────────────────────────────────────────────────┤
│  ① 行业面（25%）       β：选对赛道                  │
│  ② 核心竞争力（30%）   α：选对公司                  │
│  ③ 财务面（20%）       验证：数字真实性               │
│  ④ 估值重构（15%）     γ：估值切换空间                │
│  ⑤ 影子股逻辑（5%）    事件驱动套利                   │
│  ⑥ 流动性 & 治理（5%）  防御层                       │
└──────────────────────────────────────────────────┘
                         ↓
┌──────────────────────────────────────────────────┐
│           综合评分 + 三色信号 + 反证检验             │
└──────────────────────────────────────────────────┘
                         ↓
                  投资决策与仓位管理
```

### 1.3 与 V1.0 的核心改进

| 改进项 | V1.0 | V2.0 |
|---|---|---|
| 维度数量 | 5 维 | 6 维（新增"流动性&治理"） |
| 权重分配 | 等权 20% | 按信息含量加权 |
| 评分输出 | 单一分数 | 当前分 + 趋势分 + 置信度 |
| 反证机制 | 无 | 每条护城河必须配反证条件 |
| 时间维度 | 静态 | 估值切换、影子股加入概率折扣与时间贴现 |
| 季节性处理 | 季度环比直接使用 | 同比 + 调整后环比剔除季节因子 |
| 框架迭代 | 一次性 | 季度回测 + 自我修正机制 |

## 2. 核心思想与底层逻辑

### 2.1 三层认知套利模型

```
第一层（β）→ 行业景气度    抓住产业风口
第二层（α）→ 核心竞争力    找到吃肉的人
第三层（γ）→ 估值/影子股   在认知差形成前卡位
```

**对应的投资学理论**：

| 维度 | 学术对应 | 通俗解释 |
|---|---|---|
| 行业面 | 行业贝塔 / 产业生命周期理论 | 选对池塘 |
| 核心竞争力 | 经济护城河理论（巴菲特、莫宁星） | 找到能游的鱼 |
| 财务面 | 盈利质量分析（Penman、Sloan） | 验证鱼是真活的 |
| 估值重构 | 多阶段 DCF / 戴维斯双击 | 估算空间 |
| 影子股 | 事件驱动套利（Event-driven） | 套关联红利 |
| 流动性&治理 | 公司治理理论 + 流动性溢价 | 防雷与撤退通道 |

### 2.2 三个底层假设的明确

V2.0 框架明确承认以下三个前提假设的有限性，并在框架内提供对冲机制：

1. **基本面变化能传导到股价** — A 股噪音占比高，业绩-股价相关性 R² 长期不到 0.3。**对冲机制**：引入"主力资金"作为短期信号一票否决项。

2. **信息可被普通投资者及时获取** — 产业链调研、客户认证状态等信息不对称严重。**对冲机制**：要求至少交叉验证 2 个信息源；以公告而非研报为准。

3. **框架是稳定的** — 产业风口、估值偏好每 2-3 年大切换一次。**对冲机制**：每季度回测错配率，>40% 时强制重写权重。

## 3. 六维评估体系详解

### 3.1 维度一：行业面（权重 25%）

#### 3.1.1 核心问题

> **这个赛道值不值得进入？**

回答需同时满足三个子问题：

- 需求是否真实？（不是讲故事的需求）
- 供给是否稀缺？（短期内能否快速扩张）
- 政策是否支持？（是否有刚性政策驱动）

**只有三者都成立，才是真正的高景气赛道。**

#### 3.1.2 评分标准

**基础分（CAGR 维度）：**

| CAGR 区间 | 基础分 | 描述 |
|---|---|---|
| > 40% | 85-95 | 极高景气（如 AI 算力） |
| 20-40% | 70-84 | 高景气（如商业航天） |
| 10-20% | 50-69 | 中景气（如新能源车零部件） |
| 5-10% | 30-49 | 低景气 |
| < 5% | < 30 | 衰退或停滞 |

**加分项（最高 +29 分）：**

| 项目 | 分值 | 案例参考 |
|---|---|---|
| 供给侧刚性约束 | +10 | InP 外延片生长周期 2-3 年 |
| 政策强制驱动 | +8 | IMO 碳减排法规、ITU 频轨规则 |
| 国产替代红利 | +6 | 出口管制驱动的国产替代 |
| 全球 CR3 高度集中 | +5 | TGV 全球仅 3 家 |

**最终行业面分 = MIN(基础分 + 加分, 100)**

#### 3.1.3 反景气测试（V2.0 新增）

**必须问：如果 CAGR 砍半，公司还活得下去吗？**

- **能活下去** → 真正的护城河公司，估值可给溢价
- **活不下去** → 纯赛道股，估值不能给溢价，行业分实际打 7 折

#### 3.1.4 政策反转情景测试（V2.0 新增）

针对"政策强制驱动"加分项，必须进行反向情景测试：

- 政策延期可能性（IMO 历史上多次延期）
- 政策豁免可能性（某些国家不参加）
- 国家间博弈影响（ITU 频轨执行节奏）

如果政策反转概率 > 30%，加分项打折。

#### 3.1.5 数据来源规范

CAGR 数据必须**至少交叉验证 2 家来源**，包括：

- 卖方研究报告（招商、中信、广发等头部券商至少 1 家）
- 第三方研究机构（IDC、Gartner、Frost & Sullivan、艾瑞咨询）
- 行业协会数据（中国半导体行业协会等）
- 上市公司年报披露

**记录每个 CAGR 数据的来源和发布日期，超过 12 个月的数据不可直接使用。**

### 3.2 维度二：核心竞争力（权重 30%）

#### 3.2.1 核心问题

> **公司在赛道中是否有不可替代性？**

好行业里也有坏公司，护城河决定谁能吃到景气度的红利。

#### 3.2.2 护城河四层结构

从低到高，依次更难复制：

| 层级 | 类型 | 取得周期 | 案例 |
|---|---|---|---|
| **L4** | 资质认证壁垒 | 5-8 年（不可买） | 宇航级认证、军工承制资质、JEDEC 标准参与资格 |
| **L3** | 强技术积累壁垒 | 10 年+（时间成本极高） | SerDes 技术、IDM 全栈制造、TGV 精密制孔 |
| **L2** | 客户认证壁垒 | 2-3 年（可被替代） | 进入三星/英伟达/苹果/AMD 供应链 |
| **L1** | 弱规模效应壁垒 | 资本可快速复制 | 通用代工、标准化封测 |

#### 3.2.3 三个关键检验问题

| Q | 问题 | 强护城河 | 弱护城河 |
|---|---|---|---|
| Q1 | 公司消失，客户能在 6 个月内找到替代品吗？ | 不能 | 能 |
| Q2 | 新进入者用 5 亿资本能追上吗？ | 不能 | 能 |
| Q3 | 毛利率过去 3 年趋势？ | 持续上升 | 持续下降 |

#### 3.2.4 护城河评分标准

| 评级 | 分值 | 条件 |
|---|---|---|
| L4 + 唯一量产 | 90-95 | 全球唯一/国内唯一 |
| L4 + 全球前三 | 85-90 | 资质认证 + 头部市占率 |
| L3 + 强技术 | 75-85 | 技术领先且专利布局完整 |
| L3 + 技术追赶中 | 65-75 | 技术接近但尚未达到顶尖 |
| L2 + 大客户绑定 | 60-70 | 进入头部客户供应链 |
| L1 + 规模优势 | 45-60 | 有规模但易被复制 |
| 无明显护城河 | < 45 | 价格战常态 |

#### 3.2.5 市场份额加分

| 市占率 | 加分 |
|---|---|
| > 50% 唯一量产 | +5 |
| 30-50% | +3 |
| 10-30% | +1 |
| < 10% | 0 |

#### 3.2.6 技术同源性评估（V2.0 改进）

**核心问题**：传统业务向新赛道迁移的难度。

**评估三个层次**：

1. **工艺同源性**：是否使用相似的核心工艺？
2. **精度阶跃**：新赛道对精度/寿命的要求是不是高一个数量级？
3. **客户重叠度**：原有客户是否就是新赛道的目标客户？

**警惕"同源性"陷阱**：例如汽车曲轴齿轮 → 机器人减速器，看似工艺相似，但精度要求差一个数量级（角传动误差 < 1 arcmin、寿命 > 10000h），实际迁移难度被低估。

#### 3.2.7 反证条件（V2.0 新增）

**每条护城河必须配一个"如果出现 X，护城河失效"的反证条件**：

示例：
- 若某 TGV 厂商：**如果国内 ≥3 家送样英伟达通过 → L3 降为 L2**
- 若某军工资质企业：**如果军工资质改革允许更多厂商参与 → L4 降为 L3**
- 若某苹果供应链企业：**如果苹果引入第二供应商且份额 > 30% → L2 降为 L1**

每季度 review 反证条件是否触发，触发则即时下调评分。

### 3.3 维度三：财务面（权重 20%）

#### 3.3.1 核心问题

> **数字是否验证了逻辑？**

财务面的核心目的是**验证而非预测**：用数字检验前两维（行业 + 竞争力）是不是真的。

#### 3.3.2 情况 A vs 情况 B 量化判别（V2.0 重写）

PE 几千倍可能是买入信号（情况 A），也可能是最危险的陷阱（情况 B）。V2.0 给出量化标准：

| 标准 | 情况 A（值得买） | 情况 B（陷阱） |
|---|---|---|
| 季度环比 | 连续 ≥2 季度 > 50% | 单季爆发后停滞 |
| 扣非/归母比 | > 0.85 | < 0.5 |
| 经营现金流 | 同步转正 | 持续为负 |
| 收入结构 | 主业贡献 > 70% | 非经常性 > 30% |
| 客户集中度透明度 | 前五大客户合同金额公开 | 模糊或无 |

**判定规则**：

- **5 项满足 4 项以上 → 情况 A**（真正扭亏，可重点关注）
- **2 项以上不满足 → 情况 B**（陷阱，回避）
- **中间区间 → 待观察**（暂不下结论）

#### 3.3.3 六项核心财务指标

##### 1. 毛利率趋势

**比绝对值更重要的是趋势**：

- 持续上升 → 定价权加强
- 持续下降 → 护城河被侵蚀

**绝对值阈值**：

| 行业 | 健康毛利率 |
|---|---|
| 高科技芯片 | > 60% |
| 精密制造 | > 25% |
| 服务业 | > 40% |

##### 2. 经营现金流 / 净利润

| 比值 | 信号 |
|---|---|
| > 1.0 | 现金流入真实，优质 |
| 0.5-1.0 | 正常 |
| < 0.5 | 利润存疑，需警惕 |
| < 0 | 危险信号 |

##### 3. 应收账款占比

**应收账款 / 年营收**：

| 比值 | 信号 |
|---|---|
| 20-40% | 正常制造业 |
| 40-100% | 关注资金回笼 |
| > 100% | 红灯，可能虚增收入 |

##### 4. 资产负债率

| 行业类型 | 健康线 | 黄线 | 红线 |
|---|---|---|---|
| 制造业 | < 60% | 60-70% | > 80% |
| 重资产/造船 | < 70% | 70-80% | > 85% |
| 金融类 | 不适用 | 不适用 | 不适用 |

**配合经营现金流综合评估**：高负债 + 现金流强（可控） vs 高负债 + 现金流弱（危险）

##### 5. 研发费用率

科技公司：
- > 15% → 优质
- 8-15% → 合格
- < 8% → 警惕未来竞争力衰退

##### 6. 季度环比增速（V2.0 改进）

**警惕季节性陷阱**：

- 家电、空调 Q1 历来弱、Q3-Q4 强
- 电子设备验收集中在年底
- 服装、消费电子有明显季节因子

**正确做法**：

- **同比看方向**（同比 > 30% 是基本要求）
- **调整后环比看动能**（剔除季节因子后的环比）
- **连续 3 个季度调整后环比 > 20% 是最强买入信号**

#### 3.3.4 财务面综合打分

| 项目 | 权重 |
|---|---|
| 情况 A/B 判定 | 30% |
| 毛利率趋势 | 20% |
| 经营现金流质量 | 15% |
| 应收账款健康度 | 10% |
| 资产负债率 | 10% |
| 研发费用率 | 10% |
| 季度环比动能 | 5% |

**红黄绿信号灯**：

- 6 项指标至少 4 项绿灯且情况 A → 财务面分 80+
- 2-3 项绿灯 → 财务面分 60-80
- < 2 项绿灯或情况 B → 财务面分 < 60

### 3.4 维度四：估值重构（权重 15%）

#### 3.4.1 核心问题

> **当前估值是否合理？未来从哪个体系切换到哪个体系？空间多大？**

#### 3.4.2 三大估值工具

##### 工具 1：PEG 法

```
PEG = TTM PE ÷ 净利润同比增速(%)
```

| PEG | 评级 | 操作 |
|---|---|---|
| < 0.5 | 严重低估 | 优先买入信号 |
| 0.5-1.0 | 合理偏低 | 可介入 |
| 1.0-2.0 | 合理偏高 | 等回调 |
| > 2.0 | 明显高估 | 回避 |

**适用场景**：高增速公司（净利同比 > 50%）

**注意**：PEG 法对周期性公司、利润扭亏早期公司失效，需结合工具 2 和 3 使用。

##### 工具 2：历史 PE 分位

```
当前分位 = 当前 PE / 过去 5 年 PE 均值
```

| 分位 | 评级 |
|---|---|
| < 0.5 | 历史极低位 |
| 0.5-0.8 | 偏低 |
| 0.8-1.2 | 合理 |
| 1.2-1.5 | 偏高 |
| > 1.5 | 历史极高位 |

##### 工具 3：2026E 远期 PE

```
2026E PE = 当前市值 ÷ 2026 年预测净利润
```

适用于业绩拐点期、利润非线性增长的公司。

#### 3.4.3 估值锚点切换模型（V2.0 加入概率折扣）

**核心机制**：市场对赛道认知从旧框架切换到新框架，PE 中枢跳升。

**原始空间公式**：

```
原始空间倍数 = PE_新 / PE_旧
```

**V2.0 修正公式（加入概率折扣）**：

```
预期空间 = (PE_新 / PE_旧) × 切换概率 × 业务占比 × 时间折现
```

**切换概率拆分**：

| 触发条件 | 概率加分 |
|---|---|
| 催化剂事件已发生（产业资本入主、大客户公告、技术突破） | 60% |
| 业绩季报验证（连续 2 季度净利环比增长） | +20% |
| 机构覆盖密度（卖方研报 ≥ 5 家） | +15% |
| 同业有先例（如造船周期已成功切换过） | +5% |

**最大概率 = 100%**；无法集齐的最高给 60%。

**业务占比折扣**：

```
业务占比 = 新赛道收入 / 总营收
```

如果新赛道收入占比 < 30%，估值切换的实际兑现幅度只能按业务占比计算。

**时间折现**：

```
折现因子 = 1 / (1 + 8%)^t   (t 为预计切换完成年数)
```

#### 3.4.4 估值重构评分

| PEG 区间 | 概率折扣后空间 | 综合分 |
|---|---|---|
| < 0.3 + 空间 > 3x | — | 90-95 |
| < 0.5 + 空间 > 2x | — | 80-90 |
| 0.5-1.0 + 空间 > 1.5x | — | 70-80 |
| 1.0-2.0 + 有空间 | — | 50-70 |
| > 2.0 或无明显空间 | — | < 50 |

### 3.5 维度五：影子股逻辑（权重 5%，可选）

#### 3.5.1 核心问题

> **是否存在间接受益于核心事件的低风险切入点？**

#### 3.5.2 两种类型

| 类型 | 机制 | 持续性 | 案例 |
|---|---|---|---|
| **持股型** | 持有未上市公司股权，IPO 时公允价值重估 | 一次性 | A 公司持有未上市 B 公司股权 |
| **业务型** | 业务直接受益于核心公司扩张 | 持续 | C 公司每块产品配 D 公司芯片 |

#### 3.5.3 弹性率公式（V2.0 重写）

**V1.0 原公式（有缺陷）**：

```
弹性率 = 持股市值增量 / 影子股当前市值
```

**V2.0 修正公式**：

```
有效弹性率 = (持股 × 估值 × 流动性折价 × 兑现概率) 
            / (影子股市值 × (1+r)^t)
```

**参数解释**：

- **流动性折价**：被投上市后会有解禁期、流动性折价（通常 0.5-0.7）
- **兑现概率**：IPO 不一定按预期估值（通常 0.5-0.8）
- **时间贴现**：r = 8%，t = 预计上市年数

#### 3.5.4 弹性率阈值（V2.0 调整）

| 有效弹性率 | 评级 | 操作 |
|---|---|---|
| > 5% | 强弹性 | 有配置价值 |
| 2-5% | 中等弹性 | 情绪联动为主 |
| < 2% | 弱关联 | 不专门买入 |

#### 3.5.5 影子股四步筛选法

1. **确定核心事件**：IPO、并购整合、产能扩张
2. **穿透股东结构**：查招股书/年报前十大股东
3. **计算有效弹性率**：用 V2.0 公式
4. **核实主业健康度**：影子股是"额外收益"，主业不能亏损严重

---

### 3.6 维度六：流动性 & 治理（权重 5%，V2.0 新增）

#### 3.6.1 核心问题

> **能不能买得进去、卖得出来？管理层是否可信？**

#### 3.6.2 评估指标

##### 流动性

| 指标 | 标准 |
|---|---|
| 日均成交额 | > 1 亿元（健康） |
| 日均成交额 | 5000 万 - 1 亿元（关注） |
| 日均成交额 | < 5000 万元（流动性不足，扣 20%） |

##### 大股东行为

| 行为 | 影响 |
|---|---|
| 大股东持续增持 | +5 分 |
| 大股东减持 < 1% | 中性 |
| 大股东减持 > 5% 或解禁压力大 | 扣 15% |
| 实控人变更 < 6 个月 | 一票否决 |

##### 治理透明度

| 项目 | 标准 |
|---|---|
| 年报、季报按时披露 | 必须 |
| 重大合同公开 | 加分 |
| 关联交易披露完整 | 必须 |
| ESG 重大瑕疵 | 一票否决 |

#### 3.6.3 评分标准

| 综合评级 | 分值 |
|---|---|
| 流动性强 + 治理优 | 90+ |
| 流动性中 + 治理良 | 70-90 |
| 流动性弱 + 治理一般 | 50-70 |
| 流动性弱 + 治理瑕疵 | < 50（建议放弃） |

## 4. 评分规则与权重

### 4.1 综合评分公式

```
综合评分 = 行业面 × 0.25 
        + 核心竞争力 × 0.30 
        + 财务面 × 0.20 
        + 估值重构 × 0.15 
        + 影子股 × 0.05 
        + 流动性治理 × 0.05
```

### 4.2 三色信号输出（V2.0 新增）

每个维度同时输出三个值：

| 输出 | 含义 |
|---|---|
| **当前分**（0-100）| 确定性强的部分 |
| **趋势分**（-30 到 +30） | 向上 / 平稳 / 向下 |
| **置信度**（0.0-1.0） | 你对这个判断的把握 |

**最终维度分** = 当前分 × 置信度 + 趋势分 × 0.3

### 4.3 综合评分判断标准

| 综合评分 | 评级 | 建议 |
|---|---|---|
| ≥ 85 | 强烈推荐 | 重点配置 |
| 75-84 | 重点关注 | 可分批建仓 |
| 65-74 | 轻仓观察 | 小仓位试探 |
| 55-64 | 中性观察 | 不操作 |
| < 55 | 回避 | 不买入 |

### 4.4 仓位决策矩阵

```
                       置信度高              置信度低
评分 ≥ 85            重仓 (15-20%)          轻仓 (5-8%)
评分 75-84           中仓 (8-12%)           轻仓 (3-5%)
评分 65-74           轻仓 (3-5%)            观察
评分 < 65            观察 / 回避            不操作
```

**注意**：单只标的最大仓位 ≤ 20%；同行业总仓位 ≤ 30%；保持现金 ≥ 30%。

## 5. 一票否决条款

**以下任一条件成立，无论其他维度多高都不买**：

### 5.1 治理类一票否决

- ✕ 实控人 / 董事长被刑事调查或留置
- ✕ 大股东在 12 个月内减持比例超过总持股 30%
- ✕ 实控人变更 < 6 个月
- ✕ 监管层立案调查
- ✕ ESG 重大瑕疵（环境违法、安全事故、童工等）

### 5.2 财务类一票否决

- ✕ 连续亏损 3 年 + 估值不低（PE 为负且市值虚高）
- ✕ 应收账款 > 年营收且持续增加
- ✕ 经营现金流连续 8 季度为负
- ✕ 审计机构出具非标意见

### 5.3 资金类一票否决

- ✕ 主力资金持续净流出 3 日 + 累计 > 5 亿
- ✕ 融券余额 / 流通市值 > 5%

### 5.4 例外条款

**唯一例外**：连续亏损但卡脖子技术已送样头部客户（如英伟达、台积电）且市值 < 100 亿，需有公开订单或合同公告佐证。此例外仅适用于硬科技领域。

## 6. 操作流程（SOP）

### 6.1 七步标准化分析流程

#### Step 1：行业面体检（25%）

- [ ] 拉取行业 CAGR 数据（≥ 2 个来源交叉验证）
- [ ] 分析需求、供给、政策三维度
- [ ] 计算 CR3 集中度
- [ ] 完成反景气测试（CAGR 砍半假设）
- [ ] 完成政策反转情景测试

#### Step 2：核心竞争力分层（30%）

- [ ] 判定护城河层级（L1-L4）
- [ ] 写出反证条件（必须）
- [ ] 完成三个检验问题
- [ ] 评估技术同源性（如适用）
- [ ] 计算市占率加分

#### Step 3：盈利质量验证（20%）

- [ ] 量化判定情况 A/B
- [ ] 检查 6 项核心财务指标
- [ ] 输出红黄绿信号灯
- [ ] 调整后环比剔除季节因子

#### Step 4：估值重构（15%）

- [ ] 计算 PEG
- [ ] 计算历史 PE 分位
- [ ] 估值锚点切换 + 概率折扣
- [ ] 业务占比 + 时间折现

#### Step 5：影子股弹性（5%，可选）

- [ ] 确定核心事件
- [ ] 穿透股东结构
- [ ] 用 V2.0 公式算有效弹性率
- [ ] 核实主业健康度

#### Step 6：流动性 & 治理（5%）

- [ ] 检查日均成交额
- [ ] 检查大股东行为
- [ ] 治理透明度核查
- [ ] 一票否决条款全检

#### Step 7：综合评分 + 触发条件

- [ ] 计算综合评分
- [ ] 输出三色信号
- [ ] 检查所有一票否决条款
- [ ] 候选标的需经过 2 周观察期再下决定

### 6.2 实时数据工作流

#### 数据获取标准

```
1. PE / 市值 / 历史 PE 均值 → 行情数据 API
2. 财报数据 → 上市公司公告（一手）
3. 行业数据 → 至少 2 个来源（卖方研报 + 第三方机构）
4. 主力资金 → 实时行情 API
5. 大股东行为 → 公告披露
```

#### 关键提醒

- 日期设为最近交易日（非周末、非节假日）
- 每次只查一只股票，避免数据混淆
- 公告 > 研报 > 媒体报道（信息可信度排序）
- 数据时效 ≤ 1 季度

### 6.3 决策树

```
拿到一只股票 →
  ├─ 触发任一一票否决 → 直接放弃
  └─ 通过 →
      ├─ 行业面 < 50 → 放弃
      └─ 行业面 ≥ 50 →
          ├─ 核心竞争力 < 50 → 放弃
          └─ 核心竞争力 ≥ 50 →
              ├─ 财务面情况 B → 放弃
              └─ 财务面情况 A 或待观察 →
                  ├─ 综合评分 < 65 → 观察
                  └─ 综合评分 ≥ 65 →
                      ├─ 至少 2 维绿灯 → 候选
                      └─ 仅 1 维绿灯 → 进一步观察
                          → 候选标的进入 2 周观察期
                              → 期间无重大异动 → 建仓
```

## 7. 反证机制与风险防范

### 7.1 强制反证清单

V2.0 框架要求每只标的在评估完成后必须回答：

1. **如果我错了，最可能的原因是什么？**
2. **市场上有没有公开的反方观点？**（搜索"质疑 + 公司名"）
3. **这只股票最大的风险是什么？最坏情况下亏损多少？**
4. **如果未来一年股价下跌 50%，最可能的原因是什么？**
5. **同行业有没有比这家更好的标的？**

### 7.2 自我证伪练习

每月选择持仓中评分最高的 1-2 只标的，强制做"卖出报告"：

- 假设我现在持仓，明天必须全部卖出，理由是什么？
- 列出至少 3 个卖出理由
- 评估这些理由的可信度

如果卖出报告比买入报告更有说服力，重新评估持仓。

### 7.3 时间维度风险

**估值切换、影子股套现都需要时间**：

- 估值切换：通常 6-18 个月
- IPO 退出：通常 1-3 年
- 业务转型：通常 2-5 年

**等待成本**：每年机会成本约 10-15%（股市平均回报）。

时间越长，需要的兑现概率越高才能弥补机会成本。

### 7.4 黑天鹅预留

V2.0 框架完全无法覆盖以下风险：

- 地缘政治风险（如台海、俄乌）
- 系统性金融危机
- 监管政策突变
- 公司刑事案件（实控人跑路、财务造假）

**对冲机制**：永远预留 30% 现金应对体系外的黑天鹅。

## 8. 常见陷阱与误区

### 8.1 八个最常见陷阱

| 陷阱 | 表现 | 防范 |
|---|---|---|
| 1. 故事驱动陷阱 | 只看赛道概念不看护城河 | 强制做反景气测试 |
| 2. 季节性陷阱 | 只看环比不剔除季节因子 | 用调整后环比 |
| 3. 政策依赖陷阱 | 政策一退坡公司就崩 | 政策反转情景测试 |
| 4. PE 切换幻觉 | 拍脑袋设新 PE 锚点 | 用概率折扣公式 |
| 5. 影子股纸面富贵 | 弹性率公式忽略折价 | 用 V2.0 修正公式 |
| 6. 同源性误判 | 工艺看似同源但精度阶跃 | 评估精度阶跃维度 |
| 7. 应收账款滞后陷阱 | 账面利润高但回款差 | 经营现金流/净利 > 0.5 |
| 8. 流动性陷阱 | 买得进去卖不出来 | 日均成交额 > 1 亿 |

### 8.2 评分操作误区

| 误区 | 后果 | 改正 |
|---|---|---|
| 等权重 | 季度噪音和长期 alpha 混淆 | 使用 V2.0 加权 |
| 单一打分 | 忽略趋势和置信度 | 输出三色信号 |
| 一次评估终身使用 | 框架僵化 | 季度回测 + 重评 |
| 只证实不证伪 | 确认偏误 | 强制反证清单 |
| 五维都高 = 一定好 | 可能是同一个故事重复加分 | 检查相关性 > 0.7 |

## 9. 框架自我修正

### 9.1 季度回测机制

**每季度末必做**：

1. 列出本季度所有评分 ≥ 75 分的标的
2. 统计这些标的的实际涨跌幅
3. 计算"评分高 ≠ 涨幅高"的错配率

**判断标准**：

- 错配率 < 20% → 框架健康
- 错配率 20-40% → 框架需微调（调整权重）
- 错配率 > 40% → 框架需重写（重新评估底层假设）

### 9.2 权重再校准

每年根据回测结果调整六维权重：

- 命中率高的维度 → 加权
- 命中率低的维度 → 减权
- 永远保留 5% 给"流动性 & 治理"作为防御兜底

### 9.3 框架版本管理

每次框架修改记录：

- 版本号（V2.0、V2.1...）
- 修改日期
- 修改原因（哪个维度回测错配率高）
- 影响范围

## 框架结语

V2.0 的核心精神不是"评分越高越好"，而是：

1. **承认不确定性**：每个维度都有置信度
2. **强制反证**：每个判断都要找到反方观点
3. **时间维度建模**：估值切换需要时间和概率
4. **自我修正**：框架本身按市场反馈迭代

**最重要的一条铁律**：永远预留 30% 现金，应对框架完全无法覆盖的黑天鹅。
