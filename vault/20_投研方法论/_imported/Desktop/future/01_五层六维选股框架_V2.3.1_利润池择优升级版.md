# 五层六维选股框架 V2.3.1：利润池择优升级版

> 更新日期：2026-05-25  
> 升级来源：生益电子跑输生益科技案例复盘  
> 适用范围：A 股、港股、美股个股研究；尤其适用于同一产业链多标的比较  
> 重要声明：本文档仅为研究方法论和风控框架，不构成任何投资建议、收益承诺或交易指令。

---

## 0. V2.3.1 一句话升级

V2.3.1 不推翻 V2.3 的“五层六维”，而是在六维证据层之后增加“同题材择优层”：从“谁最正宗”升级为“谁控制利润池、谁有预期差、谁能被资金持续定价”。

原 V2.3 容易选出基本面正宗标的，但在同一产业链内，市场可能更偏爱更上游、更稀缺、更有涨价权、更有资金容量、并且具备子公司并表收益的载体。V2.3.1 的目标就是修正这个偏差。

---

## 1. 保留 V2.3 的五层决策

V2.3.1 继续保留五层决策架构：

1. 风险门槛：有没有不能碰、必须降级、或只适合交易的风险。
2. 六维证据评分：行业、竞争力、财务、估值、催化剂、治理的证据质量。
3. 概率赔率：乐观、中性、悲观三情景是否划算。
4. 组合风险预算：行业、主题、客户链、宏观变量是否过度集中。
5. 执行与复盘：买入、卖出、止损、复盘日、失效条件是否清楚。

V2.3.1 新增的不是第六层，而是在第二层和第三层之间插入一个强制检查：

> 同题材择优层：同一产业链中，谁是更优表达？

---

## 2. 六维证据层仍然保留

| 维度 | 核心问题 | 核心持仓权重 | 事件驱动权重 | 题材交易权重 |
|---|---:|---:|---:|---:|
| 行业面 | 赛道是否有真实需求与周期位置 | 22% | 15% | 10% |
| 核心竞争力 | 公司是否能吃到利润，而不只是蹭到概念 | 28% | 20% | 10% |
| 财务质量 | 利润、现金流、资产负债表是否验证逻辑 | 22% | 15% | 10% |
| 估值与赔率 | 未来收益是否覆盖下行风险 | 18% | 25% | 15% |
| 催化剂 / 影子逻辑 | 是否存在可验证事件或间接受益弹性 | 5% | 20% | 35% |
| 流动性与治理 | 能否买卖、能否信任、是否有治理雷 | 5% | 5% | 20% |

V2.3.1 强调：六维分数只是证据质量，不直接等于买卖按钮。分数之后必须进入同题材择优和赔率检查。

## 3. 新增模块 A：产业链利润池评分

### 3.1 为什么新增

同一题材中，最正宗的公司不一定最赚钱；最直接的环节不一定最有定价权。A 股资金经常奖励的是利润池控制力，而不是概念贴合度。

### 3.2 评分公式

```text
产业链利润池分 = 需求强度 × 稀缺性 × 涨价能力 × 成本转嫁能力 × 客户分散度
```

为了便于落地，每项按 0-5 分：

| 子项 | 5 分标准 | 1 分标准 |
|---|---|---|
| 需求强度 | 下游需求高速增长且持续性强 | 短期脉冲或政策刺激 |
| 稀缺性 | 技术、认证、产能稀缺，替代周期长 | 产能易复制，竞争者众多 |
| 涨价能力 | 产品供需紧张，可主动提价 | 被客户压价，价格被动 |
| 成本转嫁能力 | 原材料上涨可顺利传导 | 成本上升压缩毛利 |
| 客户分散度 | 多客户、多区域、多产品验证 | 单一客户或单一订单依赖 |

### 3.3 加减分规则

| 产业链位置 | 处理 |
|---|---|
| 上游稀缺材料，有涨价权和认证壁垒 | +5 到 +10 |
| 中游制造，有订单但客户议价强 | -3 到 +3 |
| 下游组装，毛利低、替代性强 | -5 到 0 |
| 单一客户拉动的高增长 | 置信度降级 |
| 只是概念映射但无收入验证 | 催化剂不计入核心分 |

## 4. 新增模块 B：母子公司穿透比较

### 4.1 触发条件

满足任一条件必须触发：

1. 母公司持有子公司股份超过 30%。
2. 母公司对子公司并表。
3. 母公司与子公司同时上市，且市场交易同一题材。
4. 母公司同时拥有更上游或更完整产业链资产。

### 4.2 比较公式

```text
母公司综合暴露 = 自有主业价值 + 子公司股权价值 + 产业协同价值 - 控股折价

子公司综合暴露 = 纯业务弹性 - 客户集中折扣 - 产能爬坡折扣 - 估值透支折扣
```

### 4.3 强制输出表

| 项目 | 母公司 | 子公司 |
|---|---:|---:|
| 是否并表 |  |  |
| 持股比例 |  |  |
| 自有主业质量 |  |  |
| 题材直接度 |  |  |
| 上游定价权 |  |  |
| 客户集中风险 |  |  |
| 机构容量 |  |  |
| 估值赔率 |  |  |
| 相对强弱 |  |  |

### 4.4 决策规则

当母公司持股超过 50%，且母公司还有更上游核心业务时，不允许默认子公司更优。必须优先比较母公司是否是更完整表达。

## 5. 新增模块 C：预期差 / 已定价程度

### 5.1 核心思想

A 股不只奖励好业绩，更奖励超预期。已经被充分定价的好业绩，可能在披露后不涨反跌。

### 5.2 三窗口检查

```text
T-5 到 T：财报或催化剂披露前是否已经大涨？
T 到 T+3：好消息披露后是否继续上涨？
T 到 T+10：是否跑赢同题材核心标的？
```

### 5.3 判断规则

| 现象 | 结论 |
|---|---|
| 业绩好，披露后继续放量上涨 | 超预期，保留或上调 |
| 业绩好，披露后横盘或下跌 | 利好已定价，降级观察 |
| 业绩一般，但股价持续强于板块 | 可能有新预期，需查催化剂 |
| 业绩好，但跑输同题材龙头 | 存在隐性担忧或表达不优 |

---

## 6. 新增模块 D：客户集中度置信度上限

### 6.1 为什么新增

客户集中度高的公司，在景气上行时利润弹性很强，但订单节奏、议价权、认证切换、地缘风险也会被放大。不能只看高增长，不看增长来源。

### 6.2 硬规则

| 条件 | 处理 |
|---|---|
| 第一大客户收入占比 > 30% | 核心竞争力置信度上限 0.80 |
| 第一大客户收入占比 > 40% | 核心竞争力置信度上限 0.70 |
| 前五大客户收入占比 > 60% | 财务质量置信度上限 0.80 |
| 外销收入 > 50% 且客户集中 | 增加地缘和订单波动折扣 |
| 没有多客户批量验证 | 不允许定为核心持仓，只能成长观察或事件驱动 |

### 6.3 降级但不否决

客户集中不是一票否决。只有当客户集中叠加坏账、订单取消、毛利率骤降、或客户替代风险时，才进入重大风险或绝对否决。

---

## 7. 新增模块 E：二阶增长趋势

### 7.1 核心思想

同比高增长不够，还要看增速是否继续加速。市场喜欢的是盈利曲线继续上修，而不是从高增速自然回落。

### 7.2 公式

```text
增长二阶导 = 本期利润增速 - 上期利润增速
```

也可以用：

```text
增长二阶导 = 本期利润增速 - 最近 4 个季度平均利润增速
```

### 7.3 判断规则

| 二阶导 | 处理 |
|---|---|
| 明显为正 | 预期差加分 |
| 小幅为正 | 保持 |
| 明显为负但绝对增速仍高 | 不否决，但估值赔率打折 |
| 增速转负 | 财务质量和趋势分同步下调 |

---

## 8. 新增模块 F：同题材相对强弱确认

### 8.1 为什么新增

基本面研究可能告诉我们谁更正宗，但市场价格告诉我们资金正在选择谁。V2.3.1 不把价格当真理，但把持续跑输视为风险信号。

### 8.2 指标

```text
RS_20 = 个股 20 日涨幅 - 题材篮子 20 日涨幅
Pair_RS = 目标股区间涨幅 - 替代标的区间涨幅
```

### 8.3 强制比较

每只候选股至少选择 3 个同题材替代标的：

1. 同产业链上游标的。
2. 同产业链中游标的。
3. 同市值或同风格标的。

### 8.4 处理规则

| 情况 | 处理 |
|---|---|
| 基本面高分且 RS 强 | 可以进入候选 |
| 基本面高分但 RS 弱 | 降为观察，查隐性担忧 |
| 基本面一般但 RS 极强 | 只能题材交易，不可核心持仓 |
| RS 强但换手极端、连续涨停 | 仓位上限下降 |

## 9. V2.3.1 完整决策流程

1. 做风险门槛：绝对否决、重大风险、交易预警。
2. 选择策略模型：核心持仓、成长配置、事件驱动、题材交易。
3. 完成六维证据评分：每维给原始分、置信度、趋势分、证据来源。
4. 做产业链利润池评分：判断谁控制利润池和定价权。
5. 做母子公司穿透比较：如果母子公司同时上市，强制比较谁是更优表达。
6. 做预期差检查：好消息是否已被定价，披露后是否继续走强。
7. 做客户集中度折扣：高集中度限制置信度和仓位。
8. 做二阶增长趋势：判断增速是否继续加速。
9. 做同题材相对强弱：和替代标的比较资金选择。
10. 做三情景赔率：乐观、中性、悲观，计算期望收益和最大损失。
11. 做组合预算：行业、主题、客户链、宏观变量是否过度集中。
12. 输出执行计划：买入条件、卖出条件、止损、时间窗口、复盘日。

## 10. 生益电子 vs 生益科技案例校准

### 10.1 原 V2.3 容易得出的结论

生益电子是 AI PCB 直接受益标的，2025 年和 2026Q1 利润高增，题材正宗，因此容易被原 V2.3 选入候选。

### 10.2 实际市场表现

在同一轮 AI PCB / CCL 行情中，生益电子跑输生益科技。原因不是 AI PCB 逻辑错误，而是市场选择了更完整的表达方式：

1. 生益科技是 CCL 龙头，处于更上游的高速材料利润池。
2. 生益科技持有并表生益电子，能分享 PCB 子公司的利润弹性。
3. 生益科技同时具备材料涨价、产品结构升级、PCB 并表、机构容量。
4. 生益电子虽然正宗，但客户集中、外销占比高、预期已充分定价。
5. 生益科技 2026Q1 利润增速继续加速，生益电子虽高增但二阶导转弱。
6. 相对强弱上，资金持续选择生益科技，而不是生益电子。

### 10.3 V2.3.1 重打分示例

| 维度 | 生益电子 | 生益科技 |
|---|---:|---:|
| 行业景气 | 88 | 92 |
| 核心竞争力 | 76 | 90 |
| 财务质量 | 82 | 88 |
| 估值赔率 | 58 | 72 |
| 催化剂 / 影子逻辑 | 75 | 88 |
| 流动性治理 | 70 | 86 |
| 产业链利润池修正 | -6 | +8 |
| 母子公司穿透修正 | -4 | +7 |
| 预期差修正 | -10 | +8 |
| 客户集中修正 | -8 | 0 |
| 相对强弱修正 | -10 | +6 |

### 10.4 校准结论

| 股票 | 原 V2.3 可能结论 | V2.3.1 结论 |
|---|---|---|
| 生益电子 | AI PCB 正宗，高弹性候选 | 好公司，但高预期、高客户集中，降为观察 |
| 生益科技 | 母公司，弹性可能低一档 | 更完整的 AI PCB / CCL 龙头表达，优先级上调 |

## 12. V2.3.1 的新铁律

1. 不再只问“谁最正宗”，必须问“谁控制利润池”。
2. 同题材多标的必须强制横向比较，不允许孤立打分。
3. 母子公司同时上市时，必须做穿透估值和并表收益比较。
4. 好业绩不等于好买点，必须检查预期差和披露后走势。
5. 客户集中度高的高增长公司，不能直接定为核心持仓。
6. 增长不仅看同比，还要看二阶导是否继续加速。
7. 基本面高分但持续跑输同题材替代标的，必须降级观察。
8. 高分不等于重仓，仓位仍由最坏情景和组合暴露决定。

---

## 13. 一句话总结

V2.3.1 的目标是从“正宗度选股”升级为“利润池择优”。真正优先的不是概念最贴的公司，而是同时满足产业链位置好、利润池大、定价权强、预期差未透支、资金容量足、相对强弱确认、并且风险可控的公司。
