## 0. 为什么要从 V1.1 升级到 V1.2

V1.1 的核心贡献是：不再追最热的股票，而是在第一个标的首爆后，寻找同一叙事里更正宗、更稀缺、但尚未充分定价的标的。

但是“五一视界”案例暴露了一个新问题：

> 有些明牌股并不会立刻见顶。只要它成为时代级叙事的唯一锚定资产，股价上涨本身会强化市场认知，进而吸引更多资金继续买入。

这说明“明牌惩罚”不能简单一刀切。V1.2 的核心升级是：

```text
普通明牌：继续强惩罚，避免高位接盘。
叙事总龙头：不取消风险惩罚，但从“待涨模型”切换到“强龙头观察 / 接力模型”。
正宗滞后股：继续用 V1.1 的 PLS/ENOS 挖掘。
```

换句话说，V1.2 不是推翻 V1.1，而是把“明牌后继续涨”的少数强龙头从普通明牌里分离出来。

## 1. V1.1 的基础仍然保留

V1.2 继续保留 V1.1 三个核心评分：

```text
FID 首爆分 = 成交量爆发 25%
           + 涨幅强度 20%
           + 收盘强度 15%
           + 低位/首日属性 15%
           + 叙事新鲜度 15%
           + 板块联动 10%

PLS 正宗滞后分 = 映射正宗度 30%
               + 未定价程度 25%
               + 标签稀缺度 20%
               + 跨市场传播潜力 15%
               + 流动性可交易性 10%

ENOS 早期叙事机会分 = 首爆强度 25%
                    + 正宗映射 25%
                    + 未定价程度 20%
                    + 传播路径确定性 15%
                    + 交易结构健康 10%
                    + 时间窗口奖金 5%
                    - 风险惩罚
```

V1.1 的主要目标仍然是找：

- T 日首爆
- T+1 / T+2 扩散
- 正宗滞后
- 跨市场接力
- 低位补涨

V1.2 只新增一个更高层的判断：当首爆股已经明牌但仍持续上涨时，判断它到底是“普通明牌”还是“叙事总龙头”。

## 2. 五一视界案例：为什么明牌后还能继续涨

五一视界持续上涨的关键，不是“明牌惩罚失效”，而是它从普通题材股变成了物理 AI 叙事的锚定资产。

其上涨路径可以概括为：

```text
物理 AI 叙事出现
→ A股相关标的先行首爆
→ 市场寻找更正宗资产
→ 五一视界被识别为 Physical AI 第一股
→ 股价上涨强化“第一股”标签
→ 媒体与资金继续引用它代表物理 AI
→ 反身性上涨形成
```

这里有三个核心条件：

1. **叙事级别足够大**：物理 AI 连接机器人、世界模型、自动驾驶、仿真训练、数字孪生与合成数据。
2. **标的足够稀缺**：市场需要一个能直接表达 Physical AI 的可交易资产。
3. **上涨强化叙事**：涨得越多，越像“第一股”；越像“第一股”，越吸引资金。

因此，五一视界不再是 V1.1 中的普通待涨标的，而是进入“叙事总龙头模式”。

## 3. 叙事级别分层

明牌后能不能继续涨，首先取决于叙事级别。

| 级别 | 类型 | 典型特征 | 明牌后处理 |
|---|---|---|---|
| C级 | 事件型小题材 | 单一新闻、单一公司、扩散弱 | 强惩罚，通常不追 |
| B级 | 板块型短题材 | 有板块联动，但持续性 2-5 天 | 明显降权，只做分歧低吸 |
| A级 | 产业型大题材 | 产业链长、分支多、可跨市场扩散 | 明牌不一刀切，看龙头地位 |
| S级 | 时代型重估 | 技术范式变化，市场持续寻找代表资产 | 允许总龙头模式切换 |

可进入总龙头模式的题材，通常至少是 A 级，最好接近 S 级。

常见 A/S 级叙事包括：

- 大模型
- 人形机器人
- 物理 AI
- 世界模型
- AI Agent 基础设施
- 先进封装 / 国产算力
- 低空经济
- 商业航天
- 端侧 AI

## 4. 新增模块：叙事强度评分 NSS

V1.2 新增 NSS（Narrative Strength Score，叙事强度分），用于判断一个叙事是否足够支持明牌龙头继续上涨。

```text
NSS 叙事强度分 = 产业空间 20%
               + 技术范式变化 20%
               + 政策/巨头催化 15%
               + 产业链扩散宽度 15%
               + 跨市场传播能力 10%
               + 媒体解释密度 10%
               + 连续催化能力 10%
```

| NSS | 叙事等级 | 处理 |
|---:|---|---|
| ≥ 80 | S级 | 允许总龙头模式 |
| 65-79 | A级 | 明牌龙头可观察，滞后股优先 |
| 50-64 | B级 | 明牌明显降权 |
| < 50 | C级 | 明牌强惩罚，原则上不追 |

注意：NSS 评分的是“叙事”，不是单只股票。  
题材很强，不代表任何相关股票都能买。

## 5. 新增模块：总龙头识别评分 TLR

TLR（Total Leader Recognition，总龙头识别分）用于判断明牌股是否具备“总龙头豁免 / 模式切换”资格。

```text
TLR 总龙头识别分 = 第一股/唯一股标签 20%
                 + 业务正宗度 20%
                 + 资产稀缺性 15%
                 + 股价反身性 15%
                 + 连续新催化 10%
                 + 板块带动能力 10%
                 + 跨市场锚定能力 10%
```

| TLR | 龙头类型 | 处理 |
|---:|---|---|
| ≥ 80 | 叙事总龙头 | 进入总龙头模式 |
| 65-79 | 分支龙头 | 降权观察，只做分歧承接 |
| 50-64 | 强势跟风 | 明牌惩罚 |
| < 50 | 普通明牌 | 强惩罚 / 回避 |

总龙头必须同时满足：

- NSS ≥ 75
- TLR ≥ 80
- 不是纯蹭概念
- 有持续成交额和换手支持
- 能带动同叙事其他股票上涨

## 6. 明牌惩罚升级为“明牌分型”

V1.1 的明牌惩罚保留，但 V1.2 增加分型判断。

| 类型 | 特征 | 处理 |
|---|---|---|
| 普通明牌 | 全网都知道，但业务关联弱或只是跟风 | 强惩罚，不进入推荐池 |
| 强势分支龙头 | 分支正宗，但不是叙事唯一锚 | 降权观察，只做分歧承接 |
| 叙事总龙头 | 第一股/唯一股/正宗稀缺/能反身性强化叙事 | 切换到总龙头模式 |
| 明牌高潮 | 连续大涨、极端换手、后排补涨末端 | 禁止追高，只做风向标 |

V1.2 的新规则：

```text
若明牌股 NSS < 75 或 TLR < 80：
    继续按 V1.1 明牌惩罚处理。

若明牌股 NSS ≥ 75 且 TLR ≥ 80：
    不再用 ENOS 待涨模型评估买点；
    改为进入 TLM 总龙头模式。
```

## 7. 新增模块：TLM 总龙头模式

TLM（Total Leader Mode）不是“继续推荐追高”，而是把总龙头作为独立交易模式。

```text
TLM 总龙头可参与分 = 龙头地位 25%
                   + 叙事强度 20%
                   + 承接质量 20%
                   + 板块扩散 15%
                   + 新催化持续性 10%
                   + 换手健康度 10%
                   - 高位退潮风险
```

### 7.1 总龙头模式允许什么

- 允许把总龙头作为叙事温度计。
- 允许在分歧后承接强时小仓参与。
- 允许用它判断同叙事滞后股是否仍有补涨机会。
- 允许它在模型中保留高地位，而不是被普通明牌直接打死。

### 7.2 总龙头模式禁止什么

- 禁止因为“还在涨”就无脑追高。
- 禁止在高开急拉时追。
- 禁止把总龙头当低风险待涨标的。
- 禁止用 V1.1 的 ENOS 分数替代盘口纪律。

### 7.3 总龙头买点纪律

| 场景 | 操作 |
|---|---|
| 高开急拉 | 不追 |
| 放量换手后收高 | 可继续观察 |
| 分歧回踩不破关键均价 | 小仓试错 |
| 板块同步扩散 | 总龙头模式有效 |
| 后排大面积掉队 | 降低参与等级 |
| 高开低走放巨量 | 退潮预警 |
| 跌破首爆以来趋势线 | 退出总龙头模式 |

## 8. V1.2 总评分框架

V1.2 不再只有一个评分，而是先判断模式，再选择评分体系。

```text
Step 1：识别叙事
Step 2：计算 NSS 叙事强度
Step 3：识别 FID 首爆股
Step 4：判断是否明牌
Step 5：若非明牌，用 ENOS 找早期机会
Step 6：若明牌，计算 TLR
Step 7：TLR 达标则切换 TLM 总龙头模式
Step 8：TLR 不达标则执行明牌惩罚
Step 9：继续扫描 PLS 正宗滞后 / 跨市场接力 / 低位补涨
```

### 8.1 模式选择表

| 条件 | 模式 | 主要输出 |
|---|---|---|
| FID 高，未明牌 | 早期点火模式 | 首爆观察 / 低吸试错 |
| FID 已确认，PLS 高，涨幅低 | 正宗滞后模式 | 待涨候选 |
| A股先涨，港股/美股未动 | 跨市场接力模式 | 滞后市场映射 |
| 明牌但 NSS/TLR 不够 | 普通明牌惩罚 | 降权 / 回避 |
| 明牌且 NSS/TLR 高 | 总龙头模式 | 龙头观察 / 接力纪律 |
| 总龙头退潮 | 扩散退潮模式 | 全题材降温 |

## 9. 五一视界规则沉淀

五一视界案例沉淀为以下规则：

```text
若某标的同时满足：
1. 被市场明确称为某新叙事第一股或唯一股；
2. 业务与叙事高度重合；
3. 叙事级别为 A/S 级；
4. 股价上涨后媒体解释密度继续提升；
5. 出现连续催化，而不是单日新闻；
6. 能带动同叙事其他股票补涨；
则该标的不按普通明牌处理，而进入总龙头模式。
```

五一视界对应：

| 条件 | 是否满足 |
|---|---|
| Physical AI 第一股标签 | 是 |
| 数字孪生 / 仿真 / 合成数据正宗 | 是 |
| 物理 AI 叙事级别高 | 是 |
| 股价上涨强化第一股认知 | 是 |
| 连续催化 | 是 |
| 跨市场稀缺资产 | 是 |

结论：

```text
五一视界不是 V1.1 失效案例；
它是 V1.2 总龙头模式的典型样本。
```

## 10. 总龙头与滞后股如何联动

总龙头本身不一定是最佳买点，但它能帮助判断同叙事是否仍有扩散空间。

### 10.1 总龙头继续强

若总龙头继续放量上涨，且板块不退潮：

- 继续扫描 PLS 正宗滞后股。
- 优先找低位、业务更正宗、但尚未被全网点名的标的。
- 跨市场映射继续有效。

### 10.2 总龙头高位震荡

若总龙头高位震荡但不破趋势：

- 降低追高意愿。
- 寻找补涨，但仓位降低。
- 重点看板块是否还有新增首爆股。

### 10.3 总龙头退潮

若总龙头放巨量高开低走，或连续跌破关键支撑：

- 同叙事所有后排降权。
- 低位补涨暂停。
- 只保留真正基本面验证的中线标的。

```text
普通明牌惩罚 = 20-40 分
明牌高潮惩罚 = 35-60 分
总龙头高位风险惩罚 = 10-35 分
```

|---|---:|

| 连续 3 日涨幅 > 50% | +25 |

总龙头不是免罚，而是从“明牌惩罚”切换为“龙头退潮风险惩罚”。

## 13. 操作 SOP

```text
拿到一个热门叙事
→ 1. 判断叙事级别，计算 NSS
→ 2. 找到第一个大涨/首爆标的，计算 FID
→ 3. 判断首爆标的是否已经明牌
→ 4. 若未明牌，按 V1.1 找 ENOS 机会
→ 5. 若已明牌，计算 TLR
→ 6. TLR ≥ 80，进入总龙头模式
→ 7. TLR < 80，执行明牌惩罚
→ 8. 同时扫描 PLS 正宗滞后、跨市场接力、低位补涨
→ 9. 用总龙头走势判断题材温度
→ 10. 若总龙头退潮，同叙事后排全部降权
```

## 15. V1.2 核心原则

1. **普通明牌继续罚**：全网都知道但不稀缺、不正宗的票，越热越危险。
2. **总龙头不硬杀**：如果是时代级叙事的唯一锚，明牌后可能继续涨。
3. **总龙头不等于可追高**：它只是模式切换，不是无脑买入。
4. **滞后股仍是主战场**：大多数情况下，V1.2 仍优先找正宗滞后和低位补涨。
5. **龙头是温度计**：总龙头继续强，后排有扩散机会；总龙头退潮，后排风险更大。
6. **叙事越大，明牌惩罚越要精细**：C/B 级题材明牌强罚，A/S 级题材允许总龙头模式。
7. **模式不能混用**：用 ENOS 买待涨，用 TLM 看龙头；不要用待涨逻辑追高总龙头。

## 16. 一句话总结

V1.2 的核心升级是：

> 明牌不是一律看空，而是先判断它是普通明牌，还是叙事总龙头。普通明牌继续惩罚；叙事总龙头切换到强龙头观察模式；真正的主战场仍然是同叙事里的正宗滞后、跨市场接力和低位补涨。

五一视界继续上涨说明：  
**当叙事足够大、资产足够稀缺、股价上涨能反向强化“第一股”认知时，明牌股会进入总龙头反身性上涨阶段。**

这不是 V1.1 失效，而是 V1.2 必须新增的高级分支。
