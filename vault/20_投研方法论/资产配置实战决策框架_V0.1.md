# 资产配置实战决策框架 V0.1

> 本框架用于个人投资研究、组合复盘和交易纪律管理，不构成投资建议、收益承诺或交易指令。

## 0. 一句话定位

资产配置实战决策框架，是把“宏观环境雷达、V2.3.1 选股框架、题材雷达 V1.2”落到真实持仓上的执行系统。

```text
宏观环境雷达 V0.2：决定今天/本周能不能进攻，仓位上限是多少。
V2.3.1：决定每个核心标的是否值得持有、加仓、降级或剔除。
题材雷达 V1.2：决定题材仓是否允许参与，以及是否进入总龙头/补涨/退潮模式。
资产配置框架：把上述判断转成组合动作。
```

### 3.2 股票仓位分类

每只股票归入一种角色：

| 类型 | 定义 | 处理方式 |
|---|---|---|
| 核心持仓 | V2.3.1 高分，产业逻辑清晰，利润池强 | 看赔率和宏观状态决定持有/加仓 |
| 成长配置 | 有产业趋势和业绩弹性，但确定性低于核心 | 控仓，重视预期差和业绩验证 |
| 事件驱动 | 政策、公告、订单、涨价等催化驱动 | 看事件是否已 price-in |
| 题材交易 | 主要由叙事、情绪、资金推动 | 严格仓位和时间窗口 |
| 防守资产 | 低波动、现金替代、红利或固收 | 用于平衡组合 |
| 问题资产 | 逻辑弱化、跑输、触发风险或无买入理由 | 优先复盘和处理 |

### 4.1 State 到组合动作

| State | 组合动作 |
|---|---|
| S0 绝对防守 | 停止新开仓，处理风险资产，提高现金 |
| S1 冰点观察 | 建观察池，不急于加仓 |
| S2 冰点转折 | 小仓试错，只做核心低吸或首爆验证 |
| S3 震荡精选 | 按 V2.3.1 精选，汰弱留强 |
| S4 结构进攻 | 提高主线和核心仓位 |
| S5 主升扩散 | 持有强势主线，分歧承接，不追高潮 |
| S6 高潮拥挤 | 降低新开仓，卖弱留强 |
| S7 退潮确认 | 暂停题材交易，检查持仓风险 |

### 4.2 总仓位上限

| State | 总仓位上限 |
|---|---:|
| S0 | 0-20% |
| S1 | 20-35% |
| S2 | 30-45% |
| S3 | 40-60% |
| S4 | 60-75% |
| S5 | 70-85% |
| S6 | 50-70% |
| S7 | 20-40% |

如果当前权益仓位高于 State 上限：

```text
不新增仓位。
先处理问题资产、题材仓、弱势资产。
核心资产是否降仓，取决于 V2.3.1 是否仍然通过。
```

```text
二阶增长：
同题材相对强弱：
三情景赔率：
组合风险预算：
执行与复盘：
```

### 5.1 持仓评级

| 评级 | 条件 | 处理 |
|---|---|---|
| A 核心保留 | V2.3.1 高分，逻辑未证伪，赔率合理 | 保留，等待合适加仓窗口 |
| B 成长观察 | 逻辑成立但证据不足或赔率一般 | 控仓，等业绩/催化验证 |
| C 事件驱动 | 催化主导，基本面未完全验证 | 设置事件失效条件 |
| D 题材交易 | 情绪和叙事主导 | 严格仓位、时间、止损 |
| E 降级处理 | 逻辑弱化、跑输、风险上升 | 减仓或替换 |
| F 一票否决 | 治理、财务、资金硬伤 | 退出研究池或持仓 |

### 5.2 强制问题

每个持仓必须回答：

```text
当初买入逻辑是什么？
这个逻辑现在是否仍然成立？
有什么证据支持？
有什么证据反证？
如果今天没有持仓，我还会买吗？
它在组合里的角色是什么？
它和其他持仓是否暴露同一风险？
```


### 6.1 题材仓处理

| 情况 | 处理 |
|---|---|
| NSS 低，纯事件小题材 | 不做核心，原则上只观察 |
| NSS 高，ENOS 高 | 可小仓早期试错 |
| PLS 高，未充分定价 | 重点观察正宗滞后 |
| TLR 高，TLM 开启 | 可作为温度计，分歧承接，不追高 |
| ET > 85 且晋级率下降 | 停止新增题材仓 |
| 明牌高潮，后排补涨末端 | 降仓或退出 |

## 7. 第五步：组合风险预算

### 7.1 集中度检查

```text
单只资产是否超过 10%？
单一行业是否超过 30%？
单一题材是否超过 20%？
题材交易总仓是否超过 10%？
同一客户链是否过度集中？
同一宏观变量是否超过 30%？
是否多只股票其实押注同一个叙事？
```

### 7.2 风险类型

| 风险 | 例子 | 处理 |
|---|---|---|
| 市场风险 | 大盘破位，情绪退潮 | 降低总仓位 |
| 行业风险 | 行业政策或周期逆转 | 降低行业暴露 |
| 题材风险 | 明牌高潮、补涨末端 | 降低题材仓 |
| 个股风险 | 财务、治理、客户集中 | 按 V2.3.1 降级 |
| 流动性风险 | 成交额不足，跌时卖不掉 | 降仓或回避 |
| 相关性风险 | 多只股票同涨同跌 | 合并风险预算 |

## 8. 第六步：动作优先级

动作顺序必须固定。

```text
先处理风险，再考虑进攻。
先处理一票否决，再处理弱逻辑。
先卖没有买入理由的，再卖有逻辑但赔率差的。
先加核心低估强逻辑，再做题材试错。
```

### 8.1 调仓优先级

| 优先级 | 动作 |
|---:|---|
| 1 | 清理一票否决或逻辑证伪资产 |
| 2 | 降低超出风险预算的行业/题材/个股 |
| 3 | 处理跑输同题材且找不到原因的资产 |
| 4 | 保留 V2.3.1 高分且逻辑未证伪资产 |
| 5 | 在 State 允许时，加核心或主线仓 |
| 6 | 在 State 和 V1.2 均允许时，小仓题材试错 |
