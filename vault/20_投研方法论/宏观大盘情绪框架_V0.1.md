# 宏观大盘情绪框架 V0.1

## 定位

本框架不是选股器，而是仓位和策略开关。

```text
V2.3.1 负责买什么。
题材雷达 V1.2 负责叙事什么时候点火。
宏观大盘情绪框架负责决定今天该不该重拳。
```

## 输出

`Market Regime Score`：0-100 分。

| 分数 | 状态 | 策略含义 |
|---:|---|---|
| 0-20 | 冰点防守 | 只处理一票否决，不主动进攻 |
| 20-40 | 弱修复 | 轻仓试错，只做高确定性 |
| 40-60 | 震荡结构 | 按框架精选，题材低仓 |
| 60-80 | 主升扩散 | 提高成长和叙事仓位 |
| 80-100 | 高潮拥挤 | 降低追高，准备退潮风控 |

## 七个维度

1. 流动性：社融、M2、DR007、国债收益率、融资余额、ETF 净申购。
2. 政策：政治局、国常会、证监会、财政、产业政策文本强度。
3. 盈利周期：PMI、PPI、库存、利润增速、业绩上修比例。
4. 市场广度：涨跌家数、均线以上股票占比、新高新低、成交额。
5. 风险偏好：涨停溢价率、涨跌停比、连板晋级率、炸板率。
6. 估值赔率：沪深300、创业板、科创、行业 PE/PB、股债性价比。
7. 全球变量：美债、美元、人民币、油、铜、黄金、港股、美股科技。

## 与现有框架关系

- 对 V2.3.1：决定核心持仓仓位上限。
- 对题材雷达 V1.2：决定能否参与 TLM 总龙头模式。
- 对 ai-stock 策略：作为组合策略的全局仓位乘数。
