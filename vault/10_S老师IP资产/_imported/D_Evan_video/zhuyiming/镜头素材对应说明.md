## 抖音素材下载情况

### 为什么一个都没有下载成功

本轮尝试了以下抖音入口：

- `https://jingxuan.douyin.com/m/video/{aweme_id}`
- `https://www.douyin.com/video/{aweme_id}`
- `https://www.iesdouyin.com/share/video/{aweme_id}/`

`yt-dlp 2026.03.17` 对这些链接返回：

```text
Fresh cookies (not necessarily logged in) are needed
```

意思是抖音接口要求“新鲜浏览器 Cookie”，不一定必须账号登录，但至少要有真实浏览器访问抖音后的会话状态。没有这个会话时，下载器拿不到真实视频接口返回的 JSON 数据。

我又用开源项目 `jiji262/douyin-downloader` 做了低风险试跑。该工具能正常安装并显示命令行帮助，但在无 Cookie 的情况下下载单个抖音链接超过 3 分钟仍无视频产出，最终手动终止。这说明问题不是单个工具失效，而是抖音平台侧风控/会话校验导致。

### 后续可执行流程

1. 在本机浏览器打开抖音并正常登录或完成风控验证。
2. 使用 `jiji262/douyin-downloader` 的 Cookie 抓取工具：

```powershell
cd C:\Users\bzsj_\AppData\Local\Temp\douyin-downloader-test
python -m uv run --project . python -m tools.cookie_fetcher --config config.yml
```

3. 登录抖音后回到终端按 Enter，让工具把 Cookie 写入 `config.yml`。
4. 使用授权 Cookie 下载单条视频到目标目录：

```powershell
python -m uv run --project . python run.py `
  -u "https://www.douyin.com/video/视频ID" `
  -p "D:\Evan\video\zhuyiming\restricted_need_authorization\douyin_requires_permission"
```

5. 下载完成后再按本项目命名规则重命名为：
