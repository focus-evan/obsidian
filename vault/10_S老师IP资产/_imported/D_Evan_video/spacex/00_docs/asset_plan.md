## 命名规则
`SXX_CYY_TZZZ_source_desc.ext`

说明：
- `SXX`：章节号，如 S01、S04
- `CYY`：该章节内素材序号，如 C01、C02
- `TZZZ`：素材类型
  - VID = 视频
  - IMG = 图片
  - AUD = 音频
  - DOC = 文档/链接清单
- `source`：来源简称，如 spacex / nasa / yt / wiki / archive
- `desc`：简短英文描述，使用下划线

示例：
- `S04_C01_VID_spacex_falcon1_flight4_success.mp4`
- `S05_C03_IMG_nasa_dragon_iss_docking.jpg`
- `S07_C02_VID_spacex_starlink_deploy.mp4`

## 下载优先级
1. 官方/机构源：SpaceX、NASA、Wikimedia Commons、Archive.org
2. 官方公开视频页：YouTube / Vimeo 官方账号
3. 辅助可公开视频：仅作内部demo占位，后续如要公开发布再复核
