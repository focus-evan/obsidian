## 项目目标

本次分成两种 IP 出镜形态：

- 小窗 IP：以方形小窗方式覆盖在原视频画面上，同样裁掉参考视频原字幕，避免双字幕干扰。

## 技术处理

1. 从参考视频 `s.mp4` 抽取 19 段 16:9 IP 候选片段，生成 `manifest_top16x9.csv` 和 `check_sheet.jpg`。
2. 使用 `token_short_base_nosub.mp4` 作为底片，避免原短版已烧字幕与新 IP 层重复叠字。
3. 全屏 IP 片段先裁掉底部原字幕区，再缩放回 1920x1080。
4. 小窗 IP 片段先裁成无字幕方形人物区域，再加白色边框后覆盖到画面左上或右上。
5. 最后重新烧录短版口播 ASS 字幕，并复用原短版音频。
6. 第二轮修正补齐底片尾帧，保证成片时长回到 `00:03:09.38`。

## 可复用经验

- 做 IP 出镜替换时，优先使用无字幕底片，再在最后统一烧当前字幕。
- 参考视频的 IP 素材即使是全屏人物，也要先裁掉源字幕区，避免新旧字幕并存。
- 小窗 IP 不宜直接缩整帧，应先裁成脸部/上半身清晰的方形区域。
- 用 manifest 记录出镜时间点，后续如果要进入剪映精修，可以直接按时间点重建轨道。
