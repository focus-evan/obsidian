一、Dify 0.15.3 与最新版本（1.1.3+）核心差异
	1. 架构与功能增强
	插件化架构（1.0+）

	重构为解耦式插件系统，支持热插拔插件（如模型供应商、工作流节点），可通过 Dify 	Marketplace 安装 120+ 插件39。

	模型配置方式变更：旧版内置模型需重新以插件形式安装（如 OpenAI、通义千问），升级后需重新配置 API Key34。

	工作流智能化

	新增 Agent 节点，支持动态任务调度和多种推理策略（旧版仅基础编排）3。

	多模态支持

	支持图像/音频交互插件（0.15.3 仅文本处理）3。

2. 性能与稳定性
	数据库优化

	大表（如 workflowruns）字段类型升级（例：total_tokens 从 INT 改为 BIGINT），避免数据溢出57。


	容器依赖调整

	新增容器 dify-plugin-daemon 管理插件，旧版 docker-compose.yaml 需同步更新镜像版本3。

3. 部署要求提升
	服务器配置

	最低要求 4核8G（旧版可运行于 2核4G），推荐 8核16G 避免卡死26。

	安全增强

	强制 HTTPS 访问，旧版 HTTP 需通过 Nginx 配置转发4。

4. 版本差异简表：

数据库兼容		PostgreSQL 基础支持		大表优化（字段类型升级）
最低服务器配置	2核4G				4核8G（推荐 8核16G）
