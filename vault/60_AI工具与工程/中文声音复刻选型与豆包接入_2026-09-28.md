# 中文声音复刻选型与豆包接入

## 事实

- 日期：2026-09-28。
- 来源：session `01a0e5c7-2817-7cb0-bbf2-5729887c345c`。
- 商业首轮候选：MiniMax Speech 2.8 HD、Fish Audio S2.1 Pro、豆包声音复刻 2.0。
- 本地首轮候选：IndexTTS 2.5、VoxCPM2；IndexTTS 适合分离音色与情感参考，VoxCPM2 的 Apache 2.0 许可更清晰。
- 豆包标准接入是火山引擎云端 API；本地部署文章分段、语气指令、试听重做、历史记录和音频合并工具，不下载模型权重，也不要求本地 GPU。
- 参考录音建议 14—30 秒、单人、干净、情绪相对一致；API Key 只保存在后端，网页不持有密钥。
- 当前没有用用户本人声音做盲听实测，因此“最佳方案”尚未确定。

## 推断

- 对中文产业文章，克制自然的平静叙述比强烈哭笑更能检验真实可用性。
- 测试应同时覆盖声音相似度、语调停顿、情感自然度、长文准确稳定性和重做次数。
- 商业平台与 GitHub 公开版本的型号和许可可能不同，不能把开源可下载等同于免费商用。
