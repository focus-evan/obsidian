# 自动化报告质量门

## 一句话结论

自动化日报必须先保证截点、来源、编码、归档和缺口披露正确，再谈结论强弱。

## 关键内容

- 持仓报告：显式持仓和 automation memory 优先，清仓股不得复活。
- A股 06:00 报告：实际延迟执行也不能使用当日盘中数据。
- V231 报告：日期不闭环、财联社数据缺口或盘中污染时，降级为观察版。
- 披露监控：正式公告和相关公告分层展示，A/H 合并但保留实际披露代码和链接。
- 所有 HTML/JSON：检查 UTF-8、无连续问号乱码 token / `U+FFFD 替换字符`、HTML 闭合、字段完整、latest/archive 哈希一致。
