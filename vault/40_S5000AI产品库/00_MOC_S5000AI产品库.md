# S5000AI产品库

## 这里管理什么

- S5000AI 产品战略、PRD、页面设计、用户路径。
- 财报体检、投资逻辑复盘、行业透视、市场解读、估值训练营、持仓诊断等 Agent。
- 小程序内容入口、转化路径、用户反馈。

## 产品原则

- 不荐股，教方法。
- 不给鱼，给渔网。
- 所有公开输出必须是教育和研究辅助，不构成投资建议。

## 优先级

1. 财报体检 Agent。
2. 投资逻辑复盘 Agent。
3. 市场解读 Agent。
4. 行业透视 Agent。
5. 估值训练营 Agent。
6. 持仓诊断 Agent。

## Agent 用途

- 产品 PRD Agent
- 用户问题分类 Agent
- 小程序问答 Agent
- 转化漏斗分析 Agent
