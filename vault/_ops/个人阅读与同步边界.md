# 个人阅读与同步边界

2026-09-25，用户明确将 Obsidian 的日常用途调整为阅读、记录自己的思考、形成长期积累。

- `01_个人空间` 是用户的个人书写区。自动同步不写入、不提炼、不迁移元数据；除用户明确指定的写作任务外，不读取其中正文生成工作周报或其他公开内容。
- `01_个人空间/00_书桌.md` 是日常入口。不能用管理表、健康度、待办总数、自动同步结果替换，也不自动向书桌增加条目。
- Codex 会话、周报、行动项和自动摘要继续保存在现有后台目录。自动摘要作为参考资料，不能冒充用户的阅读记录、观点或已审核结论。
- 只有用户主动选中的内容进入阅读书架；初始两篇明确为候选，两个问题页明确为未形成结论的起步题目。
- 新随记不要求 YAML、标签、审核或入库。个人空间排除于元数据迁移、管理看板、健康度待办统计及自动 RAG 索引。
- 公开 Git 镜像明确排除 `01_个人空间/` 和 `.obsidian/bookmarks.json`，继续排除 workspace、媒体和敏感资料；不得通过摘要、附件索引或同步日志间接复制个人正文。
- 个人空间需要备份时，使用本地或用户明确指定的私有目的地，不沿用公开镜像。
- 原有文档、资料路径及人工状态字段继续保留。此次是入口与使用方式优化，不推进会话同步检查点。

验收应关注：能否直接写随记、找回阅读出处、接续同一个问题，而非要求个人笔记达到对象化覆盖率。
