# stock_report_data 表结构说明

在 `dify-api-bzsj` 项目中，`stock_report_data` 表主要用于存储 A股和港股上市公司的各期财务报表及相关衍生计算指标。该表以 `(stock_code, iyear, iquarter)` 为唯一键。

通过分析项目中的 `StockReportData` 实体类以及 `StockReportDataConstant.java` 等常量字典文件，以下是该表的详细字段说明：

## 1. 基础信息字段

| 字段名 | 数据类型 (Java) | 含义说明 |
| :--- | :--- | :--- |
| `id` | Long | 主键 ID (自增) |
| `stock_code` | String | 股票代码 |
| `iyear` | Integer | 财报年份（如 2023） |
| `iquarter` | Integer | 财报季度/报告期（例如：3=一季报，6=中报，9=三季报，12=年报） |
| `market` | String | 市场标识（例如 CN、HK） |
| `currency` | String | 财务数据币种 |

## 2. 核心财务与成长性指标（D系列字段）

| 字段名 | 数据类型 (Java) | 含义说明 | 数据来源/备注 |
| :--- | :--- | :--- | :--- |
| `d305` | Double | 毛利率 | - |
| `d306` | Double | 净利率 | - |
| `d307` | Double | 每股收益 | 主要针对 A 股 |
| `d307_100` | Double | 每股收益（港币） | 主要针对港股 |
| `d308` | Double | 净资产收益率 (ROE) | - |
| `d309` | Double | 净利润增长率 | - |
| `d309_1` | Double | 净利润 | - |
| `d310` | Double | 营业收入增长率 | - |
| `d310_1` | Double | 营业收益（营业收入） | 主要针对 A 股 |
| `d310_100` | Double | 营业收入（港币） | 主要针对港股 |
| `d314` | Double | 资产负债率 | - |
| `d316` | Double | 市净率 (PB) | - |
| `d601` | Double | 该股三年连续成长性 | 在代码中用于评估企业未来成长能力 |

## 3. 现金流指标

| 字段名 | 数据类型 (Java) | 含义说明 |
| :--- | :--- | :--- |
| `d311` | Double | 经营性现金流 |
| `d311_1` | Double | 投资性现金流 |
| `d311_2` | Double | 筹资性现金流 |
| `d312` | Double | 净现金流 |
| `d313` | Double | 期末现金及现金等价物 |

## 4. 研发及其他指标

| 字段名 | 数据类型 (Java) | 含义说明 |
| :--- | :--- | :--- |
| `d206` | Double | 研发投入占比 |
| `d206_1` | Double | 研发费用 |
| `d304` | Double | 营业收入占比 |

## 5. 系统维护字段

| 字段名 | 数据类型 (Java) | 含义说明 | 备注 |
| :--- | :--- | :--- | :--- |
| `create_time` | Date | 创建时间 | Mybatis Plus 自动填充 |
| `update_time` | Date | 更新时间 | Mybatis Plus 自动填充 |

> [!NOTE]
> **港股特殊处理**：由于币种问题，部分涉及绝对金额的指标针对港股使用了专门的带有 `_100` 后缀的字段（如 `d310_100` 表示港币计价的营业收入，`d307_100` 表示港股每股收益），以便与 A股区分处理。
