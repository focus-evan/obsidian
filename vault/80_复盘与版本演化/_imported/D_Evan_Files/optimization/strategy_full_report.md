### 1. 🐉 龙头战法 ([dragon_head_strategy.py](file:///D:/Evan/Codes/ai-stock/api/dragon_head_strategy.py))

| 维度 | 明细 |
|---|---|
| **数据源** | AkShare 涨停板数据 + 概念板块 + 新闻快讯 |

| **优化点** | 新增"断板反包"和"首阴低吸"形态扫描 |
| **LLM增强** | `dragon_head_llm.py` 对TOP5做深度分析，输出买入理由/目标价/止损价 |

## 二、跟投建议逻辑

> 源码: [portfolio_manager.py#L1750](file:///D:/Evan/Codes/ai-stock/api/portfolio_manager.py#L1750-L1831) + [portfolio_llm.py#L598](file:///D:/Evan/Codes/ai-stock/api/portfolio_llm.py#L598-L728)

### 生成流程

```
交易完成后5分钟 → generate_follow_recommendations()
  ├─ 1. 获取当前持仓（含盈亏）
  ├─ 2. 获取当日交易记录
  ├─ 3. 获取最新推荐列表（top10）
  ├─ 4. LLM生成5只跟投建议
  └─ 5. 存入数据库
```

### LLM Prompt 结构

| 输入项 | 内容 |
|---|---|
| 组合信息 | 策略名称、总资产、收益率 |
| 持仓摘要 | 每只持仓的代码/名称/持仓量/均价/现价/盈亏% |
| 交易摘要 | 当日买卖方向/代码/名称/数量/价格/理由 |
| 推荐池 | 最新推荐的top10代码/名称/价格/评分 |
| 持有周期特征 | 按战法不同动态配置（见下表） |

### 各战法持有周期提示

| 战法 | 持有周期 |
|---|---|
| 龙头战法 | 超短线1-3天，快进快出 |
| 情绪战法 | 情绪高涨1-2天，低迷3-5天等反转 |
| 事件驱动 | 短期事件2-3天，重大政策5-10天 |
| 突破战法 | 强势突破2-3天，弱势5-7天 |
| 量价关系 | 缩量上涨3-5天，放量突破1-3天 |
| 隔夜施工法 | 超短线，尾盘买次日卖，持有一夜 |
| 均线战法 | 偏中线5-10天，跌破均线离场 |
| 综合战法 | 多战法共振，2-7天 |

### LLM输出格式

```json
{
  "stocks": [{
    "stock_code": "代码",
    "stock_name": "名称",
    "current_price": 价格,
    "target_price": 目标价,
    "stop_loss_price": 止损价,
    "position_pct": 仓位占比,
    "reason": "50字跟投理由",
    "risk_level": "低/中/高",
    "expected_return": "如8.5%",
    "holding_period": "动态配置如1-2天"
  }],
  "market_overview": "30字大盘概述",
  "strategy_summary": "30字策略总结",
  "risk_warning": "风险提示",
  "confidence_score": 1-100
}
```

### 关键规则

1. 优先选当日有交易的股票和盈利持仓
2. 所有推荐必须是**次日有上涨空间**的，不推荐已大涨透支的
3. 遵守**T+1规则**：当天买入不能当天卖出
4. `holding_period`必须根据战法特点和个股情况动态配置

## 四、综合战法盯盘指导逻辑

> 源码: [combined_watchlist_guidance.py](file:///D:/Evan/Codes/ai-stock/api/combined_watchlist_guidance.py)

### 核心流程

```
generate_guidance_for_stock()
  ├─ 1. 获取实时行情（现价/涨跌/高低/量）
  ├─ 2. 计算浮动盈亏（现价 vs 买入价）
  ├─ 3. 按命中的每个战法并发调用LLM分析
  ├─ 4. 汇总各战法分析 → 生成综合操作决策
  └─ 5. 入库保存
```

### 九大战法专项Prompt

每个战法有独立的分析模板，从该战法的核心视角分析持仓股：

| 战法 | 分析维度 |
|---|---|
| 🐉 龙头战法 | 板块龙头地位、封板资金、涨停梯队阶段、打板/锁仓/兑现 |
| 💹 情绪战法 | 市场整体情绪、情绪周期位置、人气排名、情绪拐点 |
| 📰 事件驱动 | 核心催化剂、Price-in程度、历史持续时间、第一波/二次催化 |
| 🚀 突破战法 | 阻力位有效突破、量能达标、回踩确认/假突破、支撑/止损价位 |
| 📊 量价关系 | 量价健康度、主力资金动向、异动大单、天量出货信号 |
| 🌙 隔夜施工法 | 竞价量比、次日高开预判、集合竞价方向、溢价兑现点 |
| 📈 均线战法 | 均线位置关系、多头排列、金叉/死叉、回踩加仓/跌破止损 |
| 🏦 北向资金 | 近5日增减持、操作风格、与大盘同步性、跟随卖出/加仓 |
| ⚡ 趋势动量 | RSI/DMI/布林、动量衰减、相对强弱、动量背离 |

### LLM分析输出格式（每个战法）

```json

  "key_metrics": {"指标名": "值"},
  "risk_level": "低/中/高",
  "trigger_prices": {
    "stop_loss": 止损价,
    "take_profit": 止盈价,
    "add_position": 加仓价
  }
```
