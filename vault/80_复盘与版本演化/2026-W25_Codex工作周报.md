## 重点工作拆解

### 1. 工程与平台

`ai-stock` 的主要工程结果是 LLM 调用面迁移：`api/llm_client.py` 统一到 OpenAI-compatible Chat Completions，默认模型锁定 `gpt-5.5`，并通过直接请求 `http://114.55.219.63:9999/v1/chat/completions` 验证返回 `ok`。最终使用 `git add -u` 只提交 tracked changes，保留未纳入提交的 SQL/PDF 生成物。

`s-ai-agent` 侧完成了两件事：先解释 `stock_report_refresh` 是每日核心股票财报自动刷新任务，默认 07:35 运行；随后按要求在 `.env.prod` 显式增加 `STOCK_REPORT_REFRESH_ENABLED=false`，重启生产服务后生效。另一个排查点是 `LLM agent unreachable, trying fallback`，结论不是本地 curl 是否成功，而是必须从 ECS/容器路径复现；`172.16.0.0/12` 只覆盖内网来源，若走公网出口就要放行 ECS 公网 egress `/32` 或改内部 VPC 路径。

管理后台/数据展示上，处理了产业链表格只显示部分数据的问题：普通视图下表格区域保留纵向滚动，全屏继续使用全屏高度滚动，并把截图中的英文字段做了中文含义说明。

### 4. 投研框架与产业线索

本周最重要的投研规则更新是：凡提到 `V2.3.1`、`stock-v231-selector` 或 `S五维`，默认必须深度使用完整框架，而不是打一张浅表评分表。标准路径更新为：风险门 -> S五维硬数据验证 -> 六维证据评分 -> 利润池/母子穿透/预期差/客户集中/二阶增长 -> 同题材横向 PK -> 可执行结论。

典型任务包括：

- PCB/CCL/AI材料链：把电子布、HVLP铜箔、树脂分开比较，区分短缺弹性、成本占比和利润池捕获。
- 存储链：区分“长鑫扩产链”和“存储涨价链”，不要把主题热度和经营质量混成一个结论。
- 人形机器人/Physical AI：先用点火1.2判断叙事位置，再用 V2.3.1 检查智微智能、福达股份等单股。
- 商业航天/特种芯片：紫光国微被归为有真实利润池的国产特种芯片龙头，但仍需 Q2-Q3 验证。
- 玻璃基板/TGV：鼎龙股份、联瑞新材比较时，把“更纯、更小、更稀缺”的资金偏好与当前利润表强弱分开。
- 光迅科技：按 V2.3.1 归入国产光器件/光芯片/CPO链条中叙事完整的公司之一，但不能直接等同于中际旭创式十倍核心。

Feishu 文档侧确认了一个可复用读取方法：当用户说文档已打开时，优先从浏览器 DOM 读取 `document.body.innerText`，滚动多段采集后再去重。剪辑规则不要只找“剪辑标准”标题，颜色图例和行内标注往往就是规则本体。

1. `V2.3.1` 不再是标签，而是强制深度流程；短线点火、主题正宗度、经营质量、估值赔率必须分层。

3. 官方披露监控必须保留窗口和来源，不用搜索摘要代替公告页。
4. Douyin 账号处理要先确认 profile，再下载/转写；长任务后台化比前台硬等更稳。
5. ECS 连接类问题要从真实访问路径复现，本地 curl 成功不能证明生产容器可达。
6. 中报预告筛选必须区分“已正式披露”与“机构预测/全年预期”，当前 2026 中报预告仍不是密集期。
